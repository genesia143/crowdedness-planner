# Local isolated-environment reproducibility check

On 22 November 2026, a new Python 3.9.6 virtual environment was created with the standard-library environment tooling on the same Mac. No project packages were installed. This is an isolated-environment check, **not** an independent clean-machine test, because it reused the local operating system, GTFS, workbook, OTP executable and map graph.

From the repository root, `python -m unittest discover -s tests` passed all 102 tests. Using the same original GTFS and confirmed reviewed workbook, the documented CLI was run with training dates 2026-10-01 through 2026-10-21. It matched 916,872 of 1,672,406 in-period ticket records. The new training artifact's raw SHA-256 matched the existing training artifact (`af014f5ca90068670d230a726c7b883847b68cecfc8e3c3730cccf4a39b0c71c`). The index rebuilt in this environment matched the existing Sunday-window candidate byte-for-byte (raw SHA-256 `59c0ebec4d6324e357223266cc47e504d3613df6969ff853796c4f31a71dd9bf`). The unmodified artifact hashes show this local reproduction used equivalent bytes; they do not prove representativeness or external ground truth.

The API was started with the newly built index, the original GTFS and the existing OTP 2.7.0 map graph. Health returned OK and an Anand Vihar–Shivaji Stadium request on October 22 returned 18 candidate journeys, four within 20 minutes, with all three bounded departure searches completed. No same-stretch potentially quieter alternative qualified. A separate browser check selected actual stop suggestions, showed results, and returned a clear no-result message for a deadline earlier than the fastest returned journey. These are local smoke checks, not proof of complete routing or actual comfort accuracy.

No ticket records from October 25–31 were used in training. Those dates were already evaluated for an earlier candidate and cannot be called an untouched holdout for a revised candidate. The operator-reviewed workbook and data/model/map assets are not included in Git; others must obtain them and use matching versions. Separate-machine setup, independent passenger counts, field calibration, and independent assessment of cross-route comfort remain open.
