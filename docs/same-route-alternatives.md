# Experimental same-stretch time comparison

The planner may identify one potentially quieter alternative relative to the fastest returned journey. This is a conservative **ticket-pattern heuristic**, not a calibrated comfort ranking, a seat prediction or a comparison across different routes.

The candidate must arrive within the user's time budget and optional deadline, use the same ordered sequence of route and directed stop-to-stop segments as the fastest journey, and have the same day type for each compared segment. Both journeys must have an available strict hourly relative percentile on every bus segment; missing details and broader-window estimates make them ineligible. The candidate must have a percentile no higher on any segment and lower on at least one. If several candidates qualify, the lowest mean of the per-segment percentiles wins; arrival-time choice and routing remain restricted to returned candidates. These percentiles describe each segment versus its own observed hours; they are not absolute passenger counts. The mean is unweighted by segment duration and has no physical interpretation as an occupancy percentage.

The UI labels this as “potentially quieter than fastest on the same stretches” and explains that it is provisional. The `comfortable_index` remains null: we have not validated physical comfort, statistically meaningful differences or sampling comparability across routes. If no candidate meets the conditions, no quieter alternative is asserted. Estimated later-departure options may be missed by the bounded routing search. This rule is a conservative product heuristic; synthetic tests check conditions and boundaries, but real-world value and reliability remain unvalidated.
